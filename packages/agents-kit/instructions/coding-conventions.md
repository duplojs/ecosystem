## Développement avec DuploJS

- Avant d’écrire un utilitaire ou d’utiliser une API native ou tierce, rechercher la fonction adaptée à la manipulation souhaitée dans le [routeur API]({{packagePath}}/docs/API.llms.md). Suivre les liens vers le domaine puis la référence pertinente, et utiliser l’équivalent DuploJS dès qu’il existe.
- Pour une recherche de concept ou un problème de composition, de typage ou d’erreur, consulter le [routeur des concepts]({{packagePath}}/docs/concepts.llms.md), puis uniquement les pages et exemples pertinents.
- Appliquer les contrats et patterns documentés, notamment pour les contraintes et les résultats `Either`. Ne pas inventer d’API ni contourner le typage pour résoudre un doute.
- Utiliser les skills DuploJS installés pour les procédures spécialisées liées à la tâche.

Les chemins des routeurs sont relatifs au dossier de ce fichier ; résoudre ensuite chaque lien depuis le document qui le contient.
