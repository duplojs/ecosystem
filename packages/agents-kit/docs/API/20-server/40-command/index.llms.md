## Command

Déclarer et exécuter des commandes CLI et leurs entrées typées.

### [DSCommand.create](10-create.ts)

Construire une commande nommée à placer dans un arbre de commandes.
 
### [DSCommand.createArgument](10-createArgument.ts)

Déclarer un argument positionnel validé et transmis à une commande.
 
### [DSCommand.createArrayOption](10-createArrayOption.ts)

Déclarer une option contenant plusieurs valeurs décodées.
 
### [DSCommand.createBooleanOption](10-createBooleanOption.ts)

Déclarer un flag représentant la présence d’une option.
 
### [DSCommand.createOption](10-createOption.ts)

Déclarer une option à valeur décodée par une data structure.
 
### [DSCommand.exec](10-exec.ts)

Lire les arguments du processus, valider une commande racine et exécuter son traitement.
 
### [DSCommand.execOptions](10-execOptions.ts)

Décoder les options du processus sans déclarer de commande positionnelle.
