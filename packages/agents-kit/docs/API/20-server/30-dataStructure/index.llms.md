## DataStructure

Décoder et valider les interfaces de fichiers et dossiers avec les contraintes serveur.

### [DSDataStructure.file](10-file.ts)

Décrire une interface de fichier serveur.
 
### [DSDataStructure.fileExist](10-fileExist.ts)

Exiger que l’interface représente un fichier existant.
 
### [DSDataStructure.folder](10-folder.ts)

Décrire une interface de dossier serveur.
 
### [DSDataStructure.folderExist](10-folderExist.ts)

Exiger que l’interface représente un dossier existant.
 
### [DSDataStructure.mimeType](10-mimeType.ts)

Contraindre le type MIME déduit de l’extension du fichier.
 
### [DSDataStructure.size](10-size.ts)

Contraindre la taille en octets d’un fichier.
