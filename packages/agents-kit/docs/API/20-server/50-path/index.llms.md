## Path

Normaliser les chemins issus de la plateforme et convertir les chemins DuploJS pour les API système.

### [DSPath.create](10-create.ts)

Normaliser un chemin de plateforme et retourner un Either.
 
### [DSPath.createAbsolute](10-createAbsolute.ts)

Normaliser un chemin de plateforme et vérifier qu'il est absolu.
 
### [DSPath.createAbsoluteOrThrow](10-createAbsoluteOrThrow.ts)

Normaliser un chemin absolu de plateforme ou lever une erreur.
 
### [DSPath.createOrThrow](10-createOrThrow.ts)

Normaliser un chemin de plateforme ou lever une erreur.
 
### [DSPath.createSegment](10-createSegment.ts)

Normaliser un chemin de plateforme et vérifier qu'il est un segment.
 
### [DSPath.createSegmentOrThrow](10-createSegmentOrThrow.ts)

Normaliser un segment de plateforme ou lever une erreur.
 
### [DSPath.normalize](10-normalize.ts)

Normaliser un chemin selon le système courant dans la représentation DuploJS.
 
### [DSPath.toPlatformPath](10-toPlatformPath.ts)

Convertir un chemin DuploJS en chaîne utilisable par la plateforme courante.
 
### [DSPath.toPlatformPathOrThrow](10-toPlatformPathOrThrow.ts)

Convertir un chemin DuploJS pour la plateforme ou lever une erreur.
