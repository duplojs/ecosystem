## Checker

Créer des checkers aux résultats identifiés, les utiliser dans un flux HTTP et partager leur interprétation avec un preset.

### [RouteBuilder.check](10-check.ts)

Interpréter les résultats d'un checker et enrichir le floor d'une route.
 
### [createPresetChecker](10-createPresetChecker.ts)

Créer un preset pour réutiliser la sélection et le refus d'un checker.
 
### [RouteBuilder.presetCheck](10-presetCheck.ts)

Appliquer dans une route l'interprétation partagée par un preset.
 
### [useCheckerBuilder](10-useCheckerBuilder.ts)

Définir une vérification réutilisable et ses résultats nommés.
