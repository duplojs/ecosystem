# DuploJS Ecosystem

DuploJS is an ecosystem of TypeScript libraries built on functional programming and Type-Driven Design, for building robust, strongly typed applications.

## Packages on npm

| Package | Description | npm release |
| --- | --- | --- |
| `@duplojs/lang` | Functional primitives, immutable operations, composition, and typing constraints. | [npm](https://www.npmjs.com/package/@duplojs/lang) |
| `@duplojs/server` | Typed utilities for files, system operations, and CLI commands. | [npm](https://www.npmjs.com/package/@duplojs/server) |
| `@duplojs/http` | HTTP tools for the DuploJS ecosystem. | [npm](https://www.npmjs.com/package/@duplojs/http) |
| `@duplojs/form` | Building complex, strongly typed forms for Vue. | [npm](https://www.npmjs.com/package/@duplojs/form) |
| `@duplojs/json-web-token` | Strongly typed creation and management of JSON Web Tokens. | [npm](https://www.npmjs.com/package/@duplojs/json-web-token) |
| `@duplojs/playwright` | Organizing Playwright tests into sites, pages, and components with named actions. | [npm](https://www.npmjs.com/package/@duplojs/playwright) |
| `@duplojs/tools` | Development tools and utilities for DuploJS. | [npm](https://www.npmjs.com/package/@duplojs/tools) |
| `@duplojs/code-config` | Shared configurations for TypeScript, Oxlint, Commitlint, and code quality tools. | [npm](https://www.npmjs.com/package/@duplojs/code-config) |
| `@duplojs/eslint` | Shared ESLint configurations and rules. | [npm](https://www.npmjs.com/package/@duplojs/eslint) |
